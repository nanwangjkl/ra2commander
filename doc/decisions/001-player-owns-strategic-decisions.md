# 战略决定权属于玩家

玩家希望承担指挥角色，AI 执行细节。自动撤退、救援或扩产会把玩家命令变成可被覆盖的建议，因此目标、作战去留和生产方向由玩家决定，Agent 只补全目标内的执行选择。

目标及授权条件独立于生成代码保存，宿主在提交前检查；修复和 Skill 复用不能扩大任务。生产包含真正必要的科技前置，不包含为了提速额外补电或扩建产能。代价是接受未授权造成的阻塞和损失，并承担目标建模与动作检查成本。

只用提示词约束模型更简单，但无法在代码变化时独立核验执行范围；允许 AI 自主改战略则违背产品参与方式，两者均未采用。技术故障的暂停和停车不产生撤退、换目标或生产许可。

2026-10-22：原先“歧义先澄清”由 [ADR 007](007-action-first-command-interpretation.md) 替代。多个合理候选应先选取执行，玩家后续纠正，战略目标边界继续有效。现行行为见[产品边界](../spec/requirements.md)。
