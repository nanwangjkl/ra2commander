# 仅通过玩家公开 API 接入

项目独立维护，不要求修改游戏或新增上游接口。控制对象 `window.werhd` 只存在于对局页面，既不是 Node SDK，也不是本地 HTTP 服务，因此由固定页面桥访问公开状态与动作。

不导入发布包内部类，不依赖私有对象兜底；本机补充会话、归属、台账和效果观察。这样可以独立构建与维护，代价是承担公开接口缺少稳定对局 ID、路径、统一回执和禁止追击能力等限制。修改引擎或访问内部对象虽能得到更多信息，但超出项目接入边界。

最初范围不复制游戏资源；后续经用户授权，发行包按固定清单提供站点与基础资源，仍保留公开 API 控制边界，来源和许可见[游戏资源](../assets/game-resources.md)。构建不能依赖相邻的私人检出目录。固定参考与兼容限制见[游戏 API](../architecture/game-api.md)。
