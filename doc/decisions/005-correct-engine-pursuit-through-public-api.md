# 通过监控纠正原生追击

游戏普通攻击和守卫可能自行追逐，公开 API 没有禁止追击开关。只在射程内发令仍无法证明后续零位移，修改引擎又违背接入边界，因此选择本机持续观察并有限停止或纠偏，接受检测和订单生效之间的短暂偏移。

引擎偏移不能扩大玩家目标，主动离开明确守区仍受约束。观察、通信和寻路存在延迟，不能承诺严格零追逐，也不能用快照回放冒充完整引擎效果验证。

2026-10-24：[ADR 008](008-command-actions-and-engine-attack.md) 替代早期把射程作为普通攻击前置的约束。普通攻击由游戏接近开火，当前地域与掩护支援各按专题规范约束，不以本记录恢复射程拒绝。

公开接口限制见[游戏 API](../architecture/game-api.md)。
