# 编队、生产与区域清敌分别表达，攻击射程交给游戏

玩家实测发现“编入现有坦克”被解析成新生产，“指定区域清敌”被拼成移动与全图进攻，摘要与操作字段也可能相互矛盾。按玩家批准的修订，现有单位编队和指定编队的区域清敌分别作为独立操作；默认从现有未编队单位选取，明确“所有”时覆盖其要求的现有单位集合，数量不足先执行可用部分并反馈，不擅自生产。展示摘要由实际绑定计划生成，模型原始解释仅保存在调试记录中。

清敌的目标分区与行军范围分开，选敌按真实异形边界（含孔洞）筛选，不把分区外敌人交给区域清敌脚本，不因赶路需要经过别区而拒绝行军。区域进攻作为同队的一个完整目标，不能由“移动＋全图进攻”互相覆盖；到达与清空分区不是同一事实，当前看不到敌人也不能证明区域已清空。

普通攻击不再以宿主估算或页面 `inRange` 作为提交前置，接近、寻路及开火条件由游戏处理。射程可以辅助微操，但不得导致命令被拒或整队停摆。目标消失、队员阵亡等过期动作跳过本次提交，结构错误及超出真实任务范围的动作仍反馈错误。此项替代 [005](005-correct-engine-pursuit-through-public-api.md) 中把射程作为攻击前置的实现约束；玩家明确的守区、回撤与目标地域仍然有效。游戏自身可能产生短暂追逐，不据此扩大任务的选敌范围。
