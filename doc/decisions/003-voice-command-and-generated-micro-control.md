# 语音指挥与本机执行生成脚本

最初目标是玩家只巡视和发语音命令，由 AI 编写目标选择、火力和站位逻辑。本机持续执行生成脚本，避免每次微操等待云端回答；代价是需要隔离、验证生成代码并观察真实效果。仅从固定技能库选动作不能满足当时的生成要求，逐动作请求云模型又增加实时延迟。

本记录的“全部微操生成、屏蔽原生单位输入”描述最初方案。后续按 [ADR 006](006-script-per-control-owner.md)、[ADR 010](010-native-production-preparation.md) 及固定流程迁移交付，基础行动已由本机处理；当前保留游戏原生输入，Deck 沿用用户个人键盘映射，没有专用输入屏蔽或转发层。具体交付见[开发里程碑](../roadmap/development-history.md)。

2026-10-22：原默认歧义澄清由 [ADR 007](007-action-first-command-interpretation.md) 替代。继续保留的原则是玩家下达目标、已有任务在模型等待期间运行；代码语法通过不能代替实际调动和交火效果验收。
