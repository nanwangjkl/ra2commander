# 快速反应优先

此前为了唯一确定盟军或苏军重工而拒绝生产，造成下令后不动。玩家明确接受误选并用后续命令纠正，因此选择结合当前可见战况作合理解释并立即执行，不为普通候选歧义增加确认轮次。

优先当前可造对象，再参考阵营和已有设施，仍有多个候选就选一个并简短反馈。多辆基地车不阻止展开，复合命令有失败部分时先推进成功部分。接受资源浪费与次优行动，以降低有目标却不行动的代价。

此项替代 [ADR 001](001-player-owns-strategic-decisions.md) 和 [ADR 003](003-voice-command-and-generated-micro-control.md) 的默认歧义澄清，保留玩家决定战略目标。确无对象、能力未接入或接口失败仍须如实报告，不能用“已执行”掩盖未行动。

普通候选准备期间保留旧任务，停止和取消立即使相关旧操作失效。评价优先看首个有效动作与空转，再看理解准确性和结果；具体行为见[产品边界](../spec/requirements.md)。
