# 游戏资源

2026-11-02 用户授权将首次资源准备改为随客户端提供、本机自动加载；随后批准客户端 3C 的 Linux 分发，将这些资源与固定站点、冰天雪地一同放入安装包，见[Linux 分发](../spec/linux-distribution.md)。

## 资源与用户数据

固定清单在 `packages/game-werhd/game-resources.json`，已转换的 MIX、启动图和菜单视频放在 `resources/game/<id>/`，当前共 23 个文件、197,719,988 字节（约 189 MiB）。正文已加入 Git 忽略，清单和准备工具纳入版本管理。资源不从开发机浏览器资料导出，也不要求玩家在首次运行时下载或转换原版安装目录。

开发准备与离线校验命令见 [AGENTS.md](../../AGENTS.md)。准备工具只在显式调用时联网，按固定 CRC32 检查每个文件，指定正文另校验大小和 SHA-256；镜像失败时换源，全部通过后才原子发布。已有目录先完整检查再复用，损坏目录报错且不覆盖。更新清单时更换资源 ID，未来构建先准备并校验这些资源，再复制进安装资源目录。

清单基于当前 ra2web 0.87.0 的官方资源镜像。核对发现上游菜单视频 CRC32 已过期，三个镜像正文一致，本地固定其正确 CRC32、大小和 SHA-256。上游残留的十个 `ls800*.png` 地址均为 404，当前游戏从 MIX 内 `ls800*.shp` 与调色板生成载入图，发行清单排除这些失效项。依据和旧校验值保留在清单备注，完整性检查不因镜像报错而放宽。

## 自动加载

宿主启动先完整校验资源，随后在同一本机源的 `/ra2c-game-resources/` 提供文件。只改写返回浏览器的 `/config.json`：自动加载开启、基础资源地址指向本机、远端基础资源候选清空、P2P 关闭。外部游戏目录中的原配置文件不改写。来源 URL 保持稳定，资源版本更新不会使浏览器保存的来源失效；视频支持 HTTP 范围读取。

游戏照常读取 manifest、校验和缓存资源，并自行保存来源偏好。`localStorage` 的 `_r_gameRes` 是来源设置，正文由游戏浏览器存储保存（优先 OPFS，可回退 IndexedDB/Cache），不靠伪造“已加载”标记跳过初始化。空白资料首次运行直接从本机资源进入主菜单，正常的启动加载进度仍会显示。资源损坏时宿主启动报错，不隐藏错误后继续加载。

Electron 必须存在完整资源后才启动宿主。浏览器 Companion 在安装本机资源后也自动使用；未准备资源时保留既有远端兼容路径。开发者可通过 `RA2C_GAME_RESOURCES_DIR` 指定完整资源目录。

## 范围与验证

基础资源准备之外，客户端构建还通过 `site-manifest.json` 固定游戏静态站点与冰天雪地正文，按 SHA-256 校验。站点文件直接从原项目 `ra2web/ra2web.github.io` 的固定提交下载，不依赖个人 fork；下载来源调整不变更固定版本与正文校验值。宿主命中该地图请求时直接提供本机文件，其他地图、音乐、MOD、战役和线上服务沿用原来源；云模型理解仍需联网。分发范围与验收见[客户端计划](../roadmap/electron-client.md)。

开发检查覆盖固定清单校验、损坏保护、失败换源、原子发布、配置不落盘、同源读取和视频范围响应。另以全新临时 Chromium 资料阻断所有外部 HTTP 请求，确认实际游戏资源选择框未出现、本机基础资源加载完成并进入主菜单；独立隐藏 Electron 也以全新数据根确认同一路径和正常退出。被阻断的远端音乐不属于本轮资源，不以静音当作完整离线验证。未进入对局、截图或提交测试命令；实机体验仍待用户验收。
