# 阶段 2：本地语音接入

2026-11-02 用户要求先提交推送已验收的阶段 1，再开始阶段 2。阶段 1 已提交 `fc1a5f3`。本轮交付真实录音、常驻本地识别和现有命令链路交接；交互及模型资源管理按用户反馈调整后，用户确认保持当前实现并要求提交推送。手动重新加载识别器保留，本轮不改为自动故障恢复；不启动客户端打包。

具体行为、接口与数据见[语音输入规范](../spec/speech-input.md)，后续顺序见[新阶段计划](client-development-phases.md)。

## 实施选择

1. 浏览器 AudioWorklet 采集，按住说话、松开提交，默认反引号键；保留文本输入和鼠标按住入口。麦克风必须由用户主动授权。
2. 采用 sherpa-onnx Node 预编译库和 SenseVoice INT8，独立进程常驻，不为每句话重新加载。提供一次性下载与校验命令，不要求手动安装外部语音服务。
3. 录音开始建立命令卡片；松开后预留现有理解队列次序，最终转写复用命令 ID、理解、绑定、执行、归档和反馈。停止/暂停、范围取消与换局仍按原规则使旧结果失效。
4. 设置页提供设备和录音键，模型目录由宿主管理并保留开发者环境覆盖，保留当前模型 URL/Key/名称表单。麦克风资源、键盘监听和异步结果由现有 UI 生命周期管理，重连不刷新游戏。

同日按用户要求补齐[模型资源管理](../assets/speech-model.md)：Git 保存固定清单及工具，模型正文移入已忽略的项目资源目录，新增离线检查并复用已有模型及下载缓存。正式程序要求随安装包内置模型，具体 build 和打包接入留到客户端阶段，本轮不新增构建入口。

## 检查与用户验收

开发检查包括音频格式、静音与非法录音、单次交接、取消/换局/优先停止、设置持久化及模拟麦克风的 iframe 按键与重连释放。337 项离线测试（含模型资源准备与校验）、类型检查和 6 项独立 UI 检查通过；本机官方中文样例已能识别，实测仅用于验证识别链路，不代替实际口述体验。

实机使用继续关注：

- 点“启用麦克风”，允许权限；焦点在游戏内，按住反引号说“展开基地”等命令，松开后观察原话、理解和实际动作。
- 连续下令、已有生产或编队执行期间再下令，确认没有重复提交，其他任务继续进行。
- 录音时按 Esc、切窗、重连或关闭麦克风，确认半句不执行、迟到结果不复活；权限拒绝后可重新启用。
- 在设置里更换设备或录音键并保存，重新启用后检查行为；实际中文兵种、建筑与分区名称以用户录音反馈为准。

不自动采集用户麦克风、不向游戏发验收命令、不截图、录屏或生成报告。实际术语识别及目标平台体验继续按用户反馈调整，客户端阶段等待单独授权。
