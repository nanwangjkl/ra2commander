## 3A 当前交付

`apps/desktop/` 创建一个 Electron `BrowserWindow`，直接承载现有游戏 iframe 与侧栏。窗口建立初始文档后才启动宿主；宿主以 Electron 内置 Node 执行原 Companion，使用当前窗口的本机 CDP 连接，不启动另一份 Chromium，不增加第二套理解或执行链路。开发模式使用 TypeScript 入口，正式包执行预编译 JavaScript。

窗口负责单实例、浏览器资料、当前本机证书及麦克风权限。游戏和侧栏均不获得 Node 权限；CDN 回包补头由窗口持有，宿主暂时断线时资源读取不依赖宿主代理。宿主启动失败或异常退出提供重试连接，保留已经加载的游戏文档。关闭窗口或菜单退出先通知宿主取消未交接命令、保存记录和释放工作进程，正常完成后由客户端销毁窗口，游戏页面的 `beforeunload` 不能再次否决应用退出；超时才终止宿主。普通页面跳转的离开行为不改写。再次启动已有客户端只激活原窗口。

开发状态复用原 `.runtime/` 中的模型设置、语音偏好和归档，Electron 浏览器资料独立在 `.runtime/desktop-profile/`；不复制或直接共用 Chromium profile，不迁移进行中的浏览器对局。基础资源经校验后从本机同源提供，新 profile 自动加载，见[游戏资源](../assets/game-resources.md)。正式包从安装资源读取模型和游戏，用户数据独立保存；`RA2C_DATA_ROOT` 可覆盖数据根。隔离检查用临时资料，不读取或改写真实对局。

原 `pnpm companion` 入口保留；两个入口默认使用同一服务和命令端口，不能同时运行。启动、构建与安装命令见 [AGENTS.md](../../AGENTS.md)。

按用户追加要求，首次使用预置音乐音量 0、主音量 2/10、屏幕虚拟摇杆关闭、卷动速率第 5 格；遭遇战预置冰天雪地、我方利比亚、法国 AI-简单。仅补充缺失的设置，玩家修改后重开保留。此项不等于实体手柄适配已完成，保存位置与格式见[游戏预置设置](../spec/game-preferences.md)。

## 检查与验收

开发检查使用独立隐藏 Electron 和模拟游戏页，覆盖内置 Node 加载识别运行库、QuickJS 隔离执行、完整宿主连接、合成麦克风采集、设置持久化、同一游戏文档保留、单实例及关闭清理。退出检查通过 Electron 主进程调用原生窗口关闭和应用退出，模拟游戏 iframe 与工作台均注册离开确认，确认保存和服务清理先于退出；不以会绕过离开确认的调试目标关闭代替原生路径。现有离线测试和工作台检查继续运行。另用官方中文样例验证当前开发机上的 Electron 本地识别，未采集用户麦克风或向游戏下测试命令。

用户验收 3A 时，在新窗口手动开局，检查文本/语音下令、当前局记录、设置和正常关闭；实际游戏动作和识别效果由用户观看。当前验证平台为 macOS Apple Silicon，SteamOS/Linux x64、原生手柄与背键、休眠恢复均尚未验收，不据此宣称 Deck 已可直接部署。

## 后续边界

3B 首先验证游戏原生手柄输入，优先将独立背键通过 Steam Input 映射到游戏未占用的现有录音键，正常松开只提交一次；其他输入不重映射或另建转发层。失焦、断连、休眠和输入中断取消录音，恢复后重新按下才开始下一句。

2026-11-02 用户批准提前实施 3C：Linux x64 AppImage 与 tar.gz、内置固定资源、正式编译与生产依赖、用户级安装和独立数据目录，见[Linux 分发](../spec/linux-distribution.md)。Docker 中检查正式产物后由用户在 SteamOS 游戏模式验收，3B 仍独立授权。首版更新通过重新安装替换程序，保留用户数据；云模型理解仍需用户配置与网络。

本轮产物已通过 Linux x64 原生中文识别、QuickJS、历史 ZIP 工作进程、真实游戏空白资料首启、冰天雪地本机读取、设置保存、退出重开及程序安装卸载检查。实际两种归档在另一干净容器中解包并逐文件核对，AppRun 的 AppImage 安装路径也通过检查；开发机完整离线回归 342 项、UI 6 项、Electron 开发入口 3 项通过。软件渲染与官方音频样例不能代替 Deck 的 GPU、实体麦克风、游戏模式和休眠验收。
