# 后续开发阶段：页面内容、语音与客户端

2026-11-01 用户确定新的开发顺序：先完善历史和设置页，再接入语音识别，最后评估 Electron 或其他打包客户端方案。已完成的功能、提交和验收记录保持原样，本计划只安排尚未完成的工作。

本计划是后续推进顺序的入口，编号与旧计划分开。原[工作台与语音计划](browser-workbench-and-voice.md)保留历史范围与交付记录，其中未实施的真实语音归入本计划阶段 2；原阶段编号不再决定后续顺序。[架构整理](architecture-consolidation.md)已经收尾，不追加新阶段。

本次确定顺序和阶段范围，不自动开始功能实现。每阶段启动时细化设计，交付后由用户验收，再按用户指令继续下一阶段。

| 后续阶段 | 交付目标 | 当前状态 |
| --- | --- | --- |
| 1 历史和设置页内容 | 已有页签可查看历史对局并管理基础设置 | 下一项，待实施 |
| 2 语音识别模块 | 录音、识别、转写提交接入现有命令链路 | 阶段 1 后安排 |
| 3 打包客户端 | 完成 Electron 或其他方案的选型、打包与启动体验 | 阶段 2 后安排 |

## 阶段 1：历史和设置页内容

历史页：

- 在已有“历史对战”页签接入本机对局列表与概览，显示时间、胜负或未结束状态、命令数和反馈情况；不要求游戏正在运行。
- 复用现有对局索引、归档读取和压缩导出能力，按需读取详情，不在侧栏加载整局战场观察。
- 详细复盘使用独立页面与 URL，展示命令原话、理解、执行结果、错误和用户反馈，支持补充反馈与导出提交包。指挥记录继续只展示当前局，命令卡片不恢复代码预览。
- 历史读取不恢复任务或重放命令，不批量改写旧原档；保持既有格式兼容和反馈保存失败可重试的行为。用途仍是玩家与开发 Agent 共同复盘。

设置页：

- 优先接入已有配置：模型服务与模型选择、界面偏好，以及连接和资源路径的状态说明。具体可编辑项在阶段设计中确认。
- 明确配置的读取、校验、保存、优先级和生效方式；可即时生效的设置立即应用，需重启的设置明确提示，不自动打断当前对局。
- 模型凭据由宿主保存与使用，页面只获取必要的配置状态。保留现有环境配置的使用方式，不因增加设置页使旧启动命令失效。
- 语音相关设置随阶段 2 接入，客户端安装与窗口管理随阶段 3 接入。

验收重点：无对局时也能查看历史，补充反馈和导出可用；切页不重载游戏或丢失当前输入；设置保存后按声明方式生效，重启仍保留。旧记录不被改写、历史操作不触发游戏动作。

## 阶段 2：接入语音识别模块

- 工作台采集麦克风音频，首版采用按住说话、松开识别提交；保留文本输入。
- 对接独立语音识别模块，沿用本地识别优先的方向；在本阶段核对后端与模型方案，验证中文及红警兵种、建筑、分区名称，不提前锁定具体引擎。
- 最终转写进入现有命令入口，复用命令 ID、理解、绑定、执行、归档与反馈，不增加独立决策链路或确认步骤。
- 正常松开只提交一次；失焦、取消、权限拒绝、设备断开和识别失败有明确状态，中间识别片段不触发动作。
- 在设置页补充设备、录音按键和识别配置；识别工作与游戏、其他指令并行，不逐句重新初始化后端。

验收重点：焦点在游戏内也能录音下令；中文转写可用且不重复提交；其他任务照常推进；异常可恢复。观察录音结束、识别、理解与首次动作各段等待，不预先承诺未经实测的延迟。

原语音计划中的交互与异常处理要求作为参考，实际后端选型和目标平台验收在本阶段确定。首版不同时扩展唤醒词、后台全局热键或多种识别引擎。

## 阶段 3：Electron 或其他打包客户端方案

- 基于前两阶段已可用的页面、配置与语音模块，对 Electron 和其他可行方案做选型验证，再确定实现；当前不预定客户端技术。
- 重点验证游戏渲染与音频、语音采集、快捷键、窗口及全屏行为，以及现有本机服务和识别进程的启动、连接与退出。
- 复用当前能力与运行时，统一处理首次资源导入、配置和对局记录存储、旧数据衔接及启动失败提示，避免再建一套命令执行系统。
- 形成可安装或直接运行的分发产物，用户无需开发终端即可启动游戏与 Companion；目标平台分别验证安装、启动、关闭和重开。

验收重点：安装或解压后能启动完整工作台；语音与命令链路可用；资源、设置和历史记录在重开后保留；退出与重新打开符合预期。目标平台、安装包形式及更新方式在选型时确定。

## 共同交付约定

- 已完成的工作台布局、当前局反馈、归档格式、游戏行为及各项本机执行不因计划重排而返工。
- 优先复用当前 UI 生命周期、记录接口、配置与模型入口；只为已确定的需求增加必要模块。
- 每阶段运行与改动相关的检查，由用户观看实机验收；不自动截图、录屏、发真实游戏测试命令或生成额外报告。
- 阶段顺序的确定不代表后续全部阶段已经获准同时实现；范围或方案明显变化时单独说明。
