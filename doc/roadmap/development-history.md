## 历史查询与授权

已完成的实施方案从现行文档移除，保留结果和对应行为规范。完整阶段、当时的验收边界与试验参数可查整理前提交 `75a463a`，例如：

```sh
git show 75a463a:doc/roadmap/architecture-consolidation.md
git show 75a463a:doc/roadmap/client-development-phases.md
git log -- doc/roadmap/
```

旧工作台计划的局部验收不等于原阶段 2、3 的整体验收；后来未完成范围已由新三阶段计划接续交付。每轮授权只适用于其明确范围，已交付功能不会自动授权其他路线图。旧计划中的候选与试验不自动视为已实现或待办。当前新增工作另定范围，分阶段工作仍需逐阶段由用户验收。
