# 实施与验证计划

本项目基于 [ra2web](https://github.com/ra2web/ra2web.github.io) 设计独立的本机语音指挥伴随程序。

状态：计划，尚无实现或实测结果。更新日期：2026-10-06。行为依据为[产品需求](../spec/requirements.md)，模块边界见[架构设计](../architecture/overview.md)。

## 首版范围

| 项目 | 首版范围 |
| --- | --- |
| 程序形态 | 独立开源的本机伴随程序，管理专用游戏窗口 |
| 平台与地图 | macOS、冰天雪地 |
| 操作方式 | 按键说话、松开提交；巡视镜头与语音下令 |
| 模型 | 本地语音识别优先；云端模型可切换 |
| 验证规模 | 100 个地面战斗单位、8 个编队与已授权生产并行 |
| 验收目标 | 命令符合度、部队调动与执行效率；bot 提供对抗环境 |

## 实施阶段

先用少量坦克、一个编队完成端到端验证，再扩展到冰天雪地、100 个地面战斗单位、8 个编队与生产并行。文本输入可用于早期调试命令编译器，最终交互使用语音。

| 阶段 | 交付物 | 验证依据 |
| --- | --- | --- |
| M1 公共 API 桥 | 专用 Chromium、固定桥、快照与动作批次、会话代次和效果观察 | 实际游戏加载成功，桥回调不被停用，旧会话动作被拒绝 |
| M2 单队完整循环 | 语音识别、对象绑定、新 JS、校验、本机持续执行；校准地域 | 守区、原地射击、战损条件、停止和普通改令符合需求 |
| M3 并行与生产 | 多编队调度、制造前置、优先级、故障修复和断网处理 | 云端等待不阻塞已有任务，无擅自生产或抢兵；队列限制可反馈 |
| M4 规模与 Skill | 100 单位/8 编队报告、群体 API 命令对比、首批经确认 Skill | 报告执行效率、延迟、识别问题和追击偏移，据实测确定性能门槛 |

## 验证方法

语法与类型检查发现接口错误，快照回放验证脚本输出和授权符合度；实际对局验证原生追击、路径、建筑落地、桥面/地面和并行开销。回放不代替引擎效果测试，bot 胜负不代替执行正确性。

对比基线采用相同玩家任务和初始条件下的普通 API 群体命令，也由程序下令。记录地图资源版本、MOD、起点、单位构成与随机性，多次场景报告分布，不把直线距离当作已知最优可达路径。

## 指标

| 指标 | 测量内容 |
| --- | --- |
| 新命令响应 | 语音结束→识别完成→理解/代码生成→校验就绪→首次有效动作，分别记录 P50/P95 |
| 持续微操延迟 | 快照 tick→本机计算→浏览器提交，记录过期批次丢弃率 |
| 集结效率 | 固定起终点的完成时间、到达比例、队形离散和实际轨迹 |
| 接战效率 | 可见合法目标前的无效等待、交火参与代理指标和重选目标及时性 |
| 发令效率 | 重复订单、每单位发令量、频繁改令的实际影响 |
| 权限符合度 | 无授权撤退、出击、追击、补员或建设；条件触发正确率 |
| 原生偏移 | 追击偏移距离、发现时刻、纠正提交时刻与观察到的恢复时刻 |
| 并行性 | 语音、云模型和某个故障脚本是否阻塞其他编队或生产 |
| 资源成本 | 游戏同时运行时的 CPU、内存、冷启动与云请求成本 |

公开 API 没有完整发射/命中事件，不能精确归因每辆坦克的伤害贡献。代理指标须注明计算方法和限制；提交成功与观察到动作效果分开记录。

兵力规模已确认，延迟、纠正距离和效率门槛尚待实测。技术选型和模型大小同样以真实游戏同时运行的数据评估，不提前宣称达到性能目标。

## 关键场景

| 场景 | 应验证的结果 |
| --- | --- |
| 10 辆坦克守桥，战损超过六成回撤 | 6 辆阵亡不触发，7 辆触发；受伤与补员不改变口径 |
| 区外射程内目标离开射程或视野 | 停止或纠正原生追击，记录偏移；不扩大授权 |
| 普通改令与“停止” | 前者就绪后切换，后者先撤权；迟到云回答不能恢复旧任务 |
| 新造单位、重叠成员与转编 | 未授权不补员，含糊冲突澄清，明确转编不被旧任务抢回 |
| 缺电、矿车损失与非法前置 | 报告阻塞，不追加战略目标，制造闭包只包含必要前置 |
| 同类与异类生产优先级 | 正确处理整类暂停和未提交顺序，不自动取消已投入项目 |
| 死亡、部署和形态转换 | 成员与战损基准正确，不把正常转换当阵亡 |
| 路径阻塞、桥面与维修停靠 | 观察实际效果与阻塞，修完不追加未经授权任务 |
| 云断网、脚本超时或异常 | 已有健康任务继续，修复不改变目标或权限 |
| 离局、页面桥失联和恢复 | 旧会话动作失效，跨局状态不复用，恢复前重新观测 |
| 巡视模式与游戏原生输入 | 保留镜头与录音，单位指令入口确实被屏蔽 |

## Skill 入库与待验证事实

候选 Skill 说明参数、版本、所需 API、适用范围和已知限制，提供代表性回放与实际场景验证；开发者审阅确认后发布，运行时只加载已登记版本。共享代码与每局状态隔离，原命令权限持续生效。

下一步需验证实际地图版本与边界、游戏加载和输入过滤、桥接持续开销、生成算法有效性、中文识别和规模性能。具体依赖版本、包装方式、重试限额、执行资源限制与性能门槛在原型中确定；这些是工程验证项，不是新的产品行为授权。
