# 本地语音输入

SenseVoiceSmall INT8 通过 sherpa-onnx 在独立子进程常驻，浏览器 AudioWorklet 采集后按句提交。原始音频默认只在内存中，不落盘或上传；转写进入现有文字命令链路，仍需云模型理解。模型来源与固定版本见[语音资源](../assets/speech-model.md)。

## 交互

页面默认启用麦克风，按住反引号（Backquote）或右侧按钮录音，正常松开才识别并下令；设备启用本身不录音。左侧开关的颜色表示开关状态，授权中显示旋转图标。语音模式在输入区背景显示音量，框内显示录音、识别或错误，不能把工具栏顶高；关闭麦克风后切换文字输入并保留草稿。

设置保留设备、录音键、保存及手动重新加载识别器。模型路径由宿主管理，页面不设置；可选按键和时限以实现为准。Electron 对本机页面音频权限放行，操作系统权限仍可能阻止；普通浏览器需要授权。文本编辑期间不拦截录音键，游戏 iframe 与外壳共用录音入口。

Esc、失焦、隐藏、设备断开、重连、换局及重载取消尚未交接的语音，不提交半句。重复按键或请求不能重复下令；识别完成交接后，关闭麦克风不会误取消已建立的游戏任务。静音、超长、设备或识别失败明确反馈，不自动改云端识别。

## 顺序与生命周期

录音开始即建立命令 ID，卡片沿用“录音 → 识别 → 理解/执行”状态。松开并接收音频时预留绑定顺序；识别与已有游戏任务、其他命令理解并行，失败或取消释放位置。迟到识别结果复查对局与取消状态，不能恢复旧令，见[命令并发](command-concurrency.md)。

设备关闭或视图卸载释放采集、监听与请求；重连保留用户开关状态，旧回调不能启用新设备。识别原生计算即使无法中断，也不得交接已取消结果。重载及退出管理子进程，失败不自动重放音频。

首版不做流式中间文字、唤醒词、后台全局热键或自动术语替换，也未启用热词。开发与资源检查命令见 [AGENTS.md](../../AGENTS.md)；实现：[packages/speech/](../../packages/speech/)、[voice-commands.ts](../../apps/companion/src/voice-commands.ts)、[语音 UI](../../apps/companion/ui/speech-audio.ts)。
