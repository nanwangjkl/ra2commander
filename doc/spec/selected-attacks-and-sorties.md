# 攻击、出击与战损

现有单位可以直接攻击，无须先编队；已编队成员沿用所属控制对象。绑定、重新理解、脚本修复与恢复始终保留本次成员、敌人类别、空地层和地域，不把攻击敌方单位扩大成所有建筑，或把区域清敌改成全图进攻。

## 地面攻击与范围

有匹配敌人时直接攻击，不先到分区中心或强制集结。普通攻击不以宿主估算射程作为门禁，接近、寻路和开火由游戏处理。无匹配目标时只在指定区域搜索，到达不等于清空区域。

“部队”“建筑”“防御设施”和空地条件按原话组合；防御设施不是全部建筑，空中步兵按实际空地层判断。普通编队默认稳定集火，明确分头才拆分；未编队成员可以独立选敌。掩护支援另保留近身和当前射程条件。

公开已知的幻影坦克可按对象 ID 强制攻击，不猜测隐藏对象。射程信息缺失时不能借防空武器的长射程假称对地支援可行。

## 飞机出击

每架飞机装弹未满时独立 pending，满弹成员可先出发，不等待全体。已接受攻击后，以实际弹药减少或新的射击冷却确认本次发射，完成该机出击；返航与装弹交给游戏，不自动反复派出，也不等待目标摧毁。不能用停车收尾打断已开火飞机的返航。

## 离场与结束

蜘蛛寄生等导致单位暂时离开公开观察时，保留同 ID 等待，不按超时猜测阵亡。载具内成员、部署和基地变形不能直接计为死亡。任务战损按原始成员基准计算，补员不重置。

全队没有存活成员且本次明确准备与交接结束后，结束任务并保留队名；不自动补兵、撤退或复活旧任务。掩护单侧耗尽见[掩护](cover-skill.md)。对局公开终态先于战损处理：胜利时活动作战任务完成，失败时失败，其他未完成目标保留真实进度，不因敌人不再可见猜测胜利。
