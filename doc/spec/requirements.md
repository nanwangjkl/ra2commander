# 产品边界

玩家用语音或文字下达目标，系统持续执行生产、组织和作战。玩家决定作战去留与生产方向，Agent 补全目标内的对象、顺序和战术细节。游戏原生输入继续可用，不另建手动接管或输入转发层。

## 执行原则

- RTS 优先快速反应。有合理解释就结合当前可见战况执行，反馈实际选择；阵营或同类候选不唯一不应导致等待确认。部分受阻时先推进其余部分，真实失败如实显示。
- 命令目标与生成代码分开保存。普通改令准备失败保留旧任务；停止、暂停、取消和换局优先使相关旧操作失效。具体顺序见[命令并发](command-concurrency.md)。
- Agent 不擅自撤退、救援、补员或扩产。制造包含必要科技前置；缺电本身不授权额外补电，明确的持续补电命令才会持续补足。
- 判断只依赖公开可观察信息。静态地图知识不提供隐藏敌军，敌人暂时不可见不等于胜利，订单提交不等于成果。

## 对象与持续任务

单位只归属一个执行编队，明确转编后停车交接；不因同兵种后来出现就自动吸收。编入现有单位与生产新单位分别表达，数量不足先执行可用部分。编队、全局管理可以并行行动，固定流程与生成脚本共用归属和实际进度。

指定区域清敌只选该区域的敌人，行军允许合理绕路。普通攻击由游戏处理接近和开火；明确守区仍保留边界。战损默认按任务生效时原始成员的阵亡比例计算，受伤不算，补员不重置；变形、载员或暂时不可观测不直接判为阵亡。

Skill 复用定义，运行状态按对局隔离。默认不自动补充战损，不恢复已取消或已经结束的任务。云模型不可用时，已有本机任务仍继续；脚本修复保持原目标和进度，固定流程故障由开发者修正。

## 当前交付范围

当前适配 ra2web 共和国之辉、冰天雪地分区，提供 Electron 客户端、浏览器开发工作台、本地语音、反馈和对局 ZIP。个人 Steam Deck 主线已验收，未做专用手柄层；macOS Apple Silicon 已构建检查，Windows 尚未完成目标平台验证。其他地图、MOD、全资源离线和通用条件语言不视为已支持。
