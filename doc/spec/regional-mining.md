# 指定分区采矿

使用现有矿车在指定分区采矿，不隐含生产或转编。只根据公开矿格选择目标，当前 API 不区分矿石与宝石，因此“有什么矿采什么矿”，不承诺按矿种筛选。

提交真实采矿动作，游戏负责采集、返厂和卸货；忙碌矿车不被每轮重发移动打断。分区限制采矿目标，不限制原生返厂或绕路路径。没有已知矿格时进入该区寻找或等待发现，到达不表示任务完成。

任务持续到取消或被替代。既有编队成员保留编队控制对象，未编队成员属于全局；发令事实同局恢复，新令、取消和换局使旧动作失效。

实现：[mining.ts](../../apps/companion/src/mining.ts)、[运行时采矿](../../packages/runtime/src/mining.ts)。
