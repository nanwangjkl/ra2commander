# 命令并发与顺序

每条命令独立并行理解，普通操作按收到顺序绑定；模型乱序返回不能使旧移动覆盖新目的地。脚本生成和规则准备不占绑定队列，已就绪的本机目标可以先行动。同轮准备均完成时仍按绑定顺序发令。

停止、暂停、取消优先处理，并按范围使更早的待理解、绑定、准备与编译结果失效。范围控制只跳过相关部分，同句其他有效操作继续；换局使旧局结果全部失效。迟到回调不得恢复旧任务或重复启动已有生成。

语音在松开并接收完整音频时预留顺序位置，识别结束沿用该位置和取消信号。后来的文字可同时理解；识别失败或取消释放位置。停止全部使更早语音失效，范围停止在理解后过滤相关操作。

正常改令准备期间旧任务继续，候选就绪后切换；普通候选失败保留旧任务。停止后的旧候选即使通过校验也不得接管。
