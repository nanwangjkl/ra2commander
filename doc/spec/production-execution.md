# 生产执行

普通生产、持续补电、显式队列控制及 Skill 的有限组件生产默认本机执行；真实规则准备独立于代码生成，所有入口共用生产台账、队列、集结与放置。只包含固定流程的语音命令通常一次理解、零代码生成。

## 数量与提交

- 有限数量累计该目标的真实新产物，不抵扣命令前已有单位，也不因阵亡补造。修改数量保留已提交与已观察产物，减少数量只收紧后续下单；撤销已入队项目须明确取消。
- 必要前置和空位共享，同名生产按提交顺序确认。提交前保存预留；订单回执不等于产出，不确定提交保留额度，不盲目重发。
- 每个目标准备独立等待或失败，迟到结果复查身份、要求和对局。修改准备失败保留旧生效要求，其他已就绪目标继续。
- 就绪建筑主动尝试放置，无合法位置时保留项目和额度，不取消重造。坦克与步兵完成[集结交接](factory-rally.md)才可指挥，矿车保留原生采矿。

## 补电与队列

持续补电以真实供耗电，加上全部已提交的待建供耗电计算缺口，显式电厂、共享前置和旧脚本提交共用事实；已建供电只计一次。满足余量后待命，耗电增加再补足，直到取消。未提交的其他建设计划不当成已有供电。

只有明确授权才暂停竞争队列，不能暂停自身仍需要的前置和产物队列。只认领正回执确认的自身暂停，不认领玩家或其他目标的暂停；恢复须公开状态确认。生产已结束即收尾恢复，不等待出厂集结。未知暂停保留待确认，不能替玩家恢复。

## 恢复与兼容

重启保留台账、实际产物、交接和队列归属，不重播未决生产或队列操作。旧无执行方式标记的目标继续脚本；显式回退保留同一目标及事实。各能力回退独立，命令见 [AGENTS.md](../../AGENTS.md)。

核心实现：[production.ts](../../packages/runtime/src/goals/production.ts)、[production-submission.ts](../../packages/runtime/src/production-submission.ts)、[production-queues.ts](../../packages/runtime/src/production-queues.ts)。取消语义见[生产取消](production-cancellation.md)，取舍见 [ADR 010](../decisions/010-native-production-preparation.md)。
