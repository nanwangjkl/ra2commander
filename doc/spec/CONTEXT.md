# 领域术语

本页只定义项目领域用语，行为约定见[产品边界](requirements.md)。

## Language

### 指挥与授权

**玩家**：
发布指挥命令并决定作战目标与生产方向的人类。

**巡视**：
观察战场与调整观察视角，不包含向单位下达游戏操作指令。

**语音命令**：
玩家以口头自然语言表达的行动要求，可能包含对象、目标、条件和限制。
_Avoid_: 模型决策（描述玩家命令时）

**战略决定**：
对编队的任务目标、作战去留或整体生产方向作出的选择，其决定权属于玩家。

**战术微操**：
在玩家任务范围内，选择具体交战目标、分配火力、调整单位站位和行动时机的执行活动。

**授权条件**：
玩家在命令中明确给出的条件及其允许的行动，例如战损达到指定阈值后回撤。
_Avoid_: 默认应急权、隐含撤退许可

**越权行动**：
超出玩家命令及授权条件的目标改变或行动。

### 战场对象

**可见战况**：
玩家在当前对局中能够观察到的战场信息。

**编队**：
作为一个指挥对象的一组己方单位，每个单位只归属一个执行编队；没有明确补员命令时不自动纳入新单位。

**掩护**：
同一编队内，指定成员靠近被保护成员、在威胁方向形成屏障并提供近身支援的持续协同行动。

**被掩护成员**：
一次掩护关系中接受保护的编队成员，和掩护成员共同组成同一个指挥对象。

**掩护成员**：
一次掩护关系中承担屏障和近身支援职责的编队成员，不另占一个编队身份。

**转编**：
玩家明确授权将单位从原编队移入另一编队的成员调整。

**编入**：
将现有单位纳入指定编队的成员调整，不包含制造新单位。
_Avoid_: 生产并编队（描述仅调整现有单位时）

**区域清敌**：
指定编队寻找并摧毁指定地图分区内敌人的任务，到达分区与完成清敌属于不同阶段。

**地图分区**：
在某套分区方案中具有确定边界和名称、可作为玩家命令目标的地图区域。

**分区方案**：
针对某个地图版本给出的一组区域边界、名称和别名；同一地图版本可以具有多套分区方案。
_Avoid_: 地图版本（描述同一地形上的不同区域划分时）

**守区**：
编队获准防守和开展局部微操的区域，可对应地图大区或桥口等固定小区。

**离区出击**：
为接敌或追击而主动离开授权守区的行动，守区内原地射击区外目标不属于离区出击。

**飞机出击**：
一架飞机在本次攻击命令中，从等待就绪到实际发射一次的行动过程。

**战损**：
任务生效时原始编队成员的阵亡比例，受伤不计入，补员不重置计算基准。
_Avoid_: 总血量损失（描述默认战损口径时）

### 生产

**游戏规则**：
当前对局规定的操作条件与效果，包括建造前置、可造项目、队列和供耗电关系。

**游戏角色**：
按用途命名的单位或建筑类别，例如侦察犬、电厂或矿场，可在不同阵营对应不同项目。

**战术约定**：
在玩家目标内安排选敌、移动、生产协调和异常处理的执行原则。

**生产**：
为战场提供单位和建筑的制造活动，受资金、电力、科技与生产设施约束。

**必要前置建设**：
为完成玩家指定制造目标而必须先完成的建设，例如建造重工所需的前置建筑。

### 任务与复用

**基础能力**：
玩家可以要求的一项明确游戏操作，例如生产、编入现有单位、移动或暂停；常规行动可以组合多项基础能力。
_Avoid_: Skill（描述单项基础操作时）

**任务目标**：
玩家命令建立的一项持续行动要求，例如制造指定数量的坦克或让某队守桥，直到完成、被替代或取消。
_Avoid_: 攻击目标（描述行动要求时）

**控制对象**：
可以独立接受改令的指挥对象，指一个编队或全局管理。

**全局管理**：
生产、建设、经济管理、编队组织与未编队单位行动的指挥范围。

**改令**：
玩家通过新命令改变已有任务要求的行为。

**命令脚本**：
承担当前对局中某个编队或全局所分配任务目标的持续执行逻辑。

**本机固定流程**：
意图和对象确定后，按预先实现的步骤持续推进、无需临时生成命令脚本的执行方式。

**编队脚本**：
负责一个编队当前移动、攻击及战术执行的命令脚本，各编队地位相同。

**全局脚本**：
负责全局管理中分配给脚本执行的当前任务目标的一份命令脚本。
_Avoid_: 永不替换的主脚本

**Skill**：
经开发者确认入库、可以跨对局复用的常规行动定义，由基础能力组合并说明执行顺序与结束条件，可附战术代码参考。
_Avoid_: Codex Skill（描述游戏能力时）

**Skill 运行**：
一次 Skill 调用在当前对局中的执行实例，固定使用调用时的定义版本、参数和行动目标。

**探索覆盖**：
指定范围中已经实际揭开黑幕的格子及其占比；经过一个落点不代表覆盖整个区域。
_Avoid_: 当前视野、路点完成率

**已揭开**：
地形黑幕已经被探索移除的状态；不保证该格子当前有敌军可见，也不证明单位能到达。
_Avoid_: 可通行、当前可见
