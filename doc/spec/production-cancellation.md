# 生产取消

“停止造矿车”等明确取消生产命令与 `goal cancel` 共用入口：立即停止追加，并撤销属于该目标、仍在游戏队列中的剩余数量。已造产物保留，其他目标仍需要的共享前置保留。全局停止、编队停止和 Skill 取消只停止后续调度，不扩大为撤销全部已入队生产。

撤销量由本目标提交和最新同名队列限量，页面桥再次复查。请求回执不算实际撤销，须观察队列变化；期间正常完工计入产出。未决提交后来入队后继续处理，不能清空账本释放额度。同名队列缺少任务归属，依赖串行记账，不能保证区分玩家手工加入的同名项目。

撤销前保存检查点，保存失败不调用游戏。重启对不明回执继续观察，不盲目重发；取消中的迟到生产回执仍须归账。重复取消只处理剩余部分，不阻塞后来新生产。旧取消目标不会因升级自动扩大撤销语义。

实现：[production-cancellation.ts](../../packages/runtime/src/production-cancellation.ts)。台账与队列边界见[生产执行](production-execution.md)。
