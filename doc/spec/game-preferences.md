# 游戏预置设置

浏览器与 Electron 共用以下首启默认值：音乐音量 0、主音量 2/10、屏幕虚拟摇杆关闭、卷动速率第 5 格；遭遇战为冰天雪地，我方利比亚，对手一个法国 AI-简单。预置不自动开始对局。

偏好由游戏原生 localStorage 选项保存，按键独立补缺；已有值整组保留，重开、升级不覆盖玩家修改。虚拟摇杆设置不代表实体手柄支持。存储不可用时报告警告并继续游戏启动。

浏览器资料与模型设置、对局记录分开，属于各入口自己的 profile，不进入调试包。原生键名、国家索引和序列化格式只维护在 [game-defaults.ts](../../packages/game-werhd/src/game-defaults.ts)，随固定站点核对，避免复制两份数值表。
