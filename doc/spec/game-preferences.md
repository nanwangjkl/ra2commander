# 游戏预置设置

2026-11-02 用户指定首次使用时音乐音量为 0、总音量为 2，随后将摇杆改为关闭、卷动速率提高一格，并指定默认遭遇战。浏览器 Companion 和 Electron 共用同一预置逻辑。

| 设置 | localStorage 键 | 保存格式 |
| --- | --- | --- |
| 主音量、音乐音量 | `_r_mixer_v3` | `channel,volume`，通道用分号分隔；主音量通道 0 为 `0.2`，音乐通道 5 为 `0` |
| 屏幕虚拟摇杆 | `ra2web.mobileJoystickLite.enabled` | `1` 开启，`0` 关闭 |
| 卷动速率 | `_r_opts_v3` | 初值 `15`，界面第 5 格，原默认 `12` 为第 4 格；只提供第一字段，其余选项沿用原生默认 |
| 遭遇战地图、模式 | `_r_lastMap`、`_r_lastMode` | `mp32s8.map` 冰天雪地，`1` 作战模式 |
| 我方国家 | `_r_lastCountry` | 固定站点可选国家索引 `5`：Africans，利比亚 |
| 电脑槽位 | `_r_lastBots` | 原生每槽五字段，八槽中仅第 1 槽为 AI-简单、法国，颜色/出生点随机，无队伍 |

界面音量范围为 0～10，内部保存 0～1，所以界面的主音量 2 对应 `0.2`。首次构造混音设置时保留上游的其他通道默认值（制作人员 `0.2`、环境 `0.3`，其余通道沿用游戏默认）。摇杆默认 `0`，指当前游戏设置里的屏幕虚拟摇杆，实体手柄输入和 Steam Deck 适配仍按[客户端计划](../roadmap/electron-client.md)另行验证。

电脑槽位依次为难度、国家、颜色、出生点、队伍。固定站点的 AI-简单为难度 `1`（内部名 Medium），`2`（Easy）实际显示 AI-弱智/训练木桩；法国国家索引为 `2`。第 0 槽为玩家，电脑记录关闭标志为国家 `-1`，颜色/出生点随机和无队伍均为 `-2`。预置不自动开始游戏，玩家仍在遭遇战界面确认。

实现位于 `packages/game-werhd/src/game-defaults.ts`。宿主在打开工作台前注册初始化脚本，只在指定源的游戏根文档与 `index.html` 中写入缺失键。游戏随后通过原有选项系统读取、显示和保存；不改外部游戏文件，不改命令侧栏设置。

只补充不存在的键，各键独立判断。已有混音、操作和遭遇战偏好整组保留；玩家修改后重开不会被预置值覆盖，升级也不重置已有设置。正在运行的游戏不强制改变音量或输入状态，清除站点设置后下次打开重新采用默认值。存储不可访问时记录警告，继续游戏原有启动流程。

这些设置属于浏览器资料：Chromium 在 `.runtime/profile/`，Electron 在 `.runtime/desktop-profile/`。开发模式位于项目，正式包位于独立[用户数据根](linux-distribution.md)。配置随对应 profile 保留，不写入模型设置文件或对局调试包。
