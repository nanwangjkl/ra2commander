# 掩护 Skill

定义：[skills/cover/SKILL.md](../../skills/cover/SKILL.md)。受护与掩护成员都属于同一个真实编队，角色不创建另一队或另一份指挥脚本。

## 成员与改令

“5辆坦克组成1队，5条狗掩护”使用现有成员；明确新造才生产，自动来源只补本次数量差额。同句已安排的生产复用，不再选满一批现有成员或重复造一批。只有本次记录关联的真实产物在集结交接后加入，不持续吸收后来同型单位。泛称防空车结合阵营识别，明确 IFV 仍保留型号。

首对成员就绪即可行动，待准备成员陆续加入，任务不能在准备未完时提前完成。角色和来源不因改移动目标、换脚本或重启丢失；转出成员不被旧来源拉回。取消掩护保留编队与当前任务，只取消自身准备；独立明确生产继续。停止整队仍立即生效，后续改令可使用保存角色。

## 行军与支援

速度使用本局真实规则，按引擎单位换算，以游戏 tick 预测。主体最慢成员持续接受终点命令，其余成员跟随前视点；掩护者更快或更慢共用这一原则。正常拉长只纠正相关成员，不通过频繁全队停车限速。补员先独立追赶主体，会合后才纳入协调。

严重掉队才有限重聚，累计等待不因短暂会合、轮换成员或同局恢复清零；暂停不计时。预算耗尽后受阻成员自行追赶，不再反复拖停主体。慢成员和真实交接仍参与到达判定，不能仅凭快成员先到跳过路点。

近敌时掩护靠近受护成员，站在其与最近威胁之间；站位受阻先回靠实际主体。主战发现合法敌人直接攻击，不先强制集结；掩护只在贴近且当前武器射程足够时支援已确认的主战目标，射程不够就待命或跟随，不单独追敌。防空掩护优先射程内空中敌人，再支援主战；区域命令仍限制选敌。无法公开读取的原生自动索敌目标不猜测。

## 损失与边界

任一侧耗尽且该侧无本次待生产或交接成员时，解除掩护，剩余成员转普通编队继续原任务，保留地域、敌人类别和路点进度。全队耗尽且准备结束才结束任务并保留队名；不补兵、不撤退，不因后来入队恢复旧任务。玩家暂停或停止继续有效。

当前仅支持地面步兵与车辆同队掩护，不包含跨队、飞行或水上护送。引擎没有整队限速或永久禁止追击接口，控制周期之间可能短暂偏离；复杂地形仍由游戏寻路处理。
