# 绑定修正与脚本修复

正常执行在本机持续进行。修复只处理明确故障或有可执行步骤却长期没有进展的脚本，不逐 tick 请求模型。

绑定失败时先启用成功部分，再针对失败项有限重新理解；已接受调用去重，不重放整句或已部分提交的 Skill。修正保留原成员、数量、分区、敌人类别与掩护职责，不扩大成全军或全图行动。直接能力调用不额外请求理解模型。

生成候选经过语法、契约和隔离干跑，错误反馈给模型有限重试；关键能力会检查准备之后的移动、开火或组装阶段，避免空脚本通过。运行连续错误会暂停对应脚本并有限修复。停滞诊断只在有资金、可造空间或真实可操作成员时计时，等待前置、装弹、未决提交、无合法落点及正常待命不算脚本空转。

故障修复保留暂停状态直到候选可用；停滞修复期间旧脚本继续，候选通过后整体切换。修复次数按对局、控制对象和目标修订限制，更换代码不清零；停止、暂停、取消、新令及换局使迟到修复失效。

模型收到旧代码、当前目标、剩余额度、最近动作和错误。宿主持有产物、归属和实际进度，换代码不能重放生产。固定本机流程出错只暂停该目标的发令并记录，其他目标继续；不请求模型重写宿主代码。用户反馈仅归档，不自动触发修复。

实现与限额：[recovery.ts](../../packages/runtime/src/recovery.ts)、[controller.ts](../../apps/companion/src/controller.ts)；修复提示在 [templates/](../../prompts/templates/)，记录见[对局归档](battle-records.md)。
