# 探路 Skill

定义：[skills/scout/SKILL.md](../../skills/scout/SKILL.md)。默认优先现有未编队侦察犬，最多三条，没有才新造；明确“用五条狗”按本次固定数量准备，明确已有成员时不足也不追加生产。参数以 Skill 定义为准。

新造犬复用生产台账，第一名完成集结交接后即可探索，其余成员陆续加入。各犬独立分配落点，优先不同分区，必要时同区分工，不等其他成员走完再下令；本机探索不另生成脚本。

每个目标分区分别达到 **60% 已揭开覆盖**才达标，全局平均不能替代逐区达标。中心优先，再向未知区域展开，不为凑满边角贴边绕行。中心从区内有效格子选取，不能落在异形区孔洞；覆盖分母使用分区与[引擎有效范围](map-regions.md)的交集。

只有实际已揭开、存在的格子增加覆盖；到达落点、移动回执或模型记得来过都不算。已揭开不表示当前有视野或可通行，未知地形不直接判不可达。宿主分批观察，存在采样延迟，不每轮扫描全图。

停滞按实际位置进展判断，允许绕路；换点、暂缓分区及最终收尾重试均有限。全部分区达标才完成，有限重试耗尽则部分完成，固定准备结束且全灭时如实结束；不无限补狗或改成进攻。历史结果保存结束时覆盖，不随其他队后来开图改写。

取消或有效新令结束旧流程的后续调度，其他生产继续；旧 Skill 不能重新接管。覆盖、落点、停滞和已确认动作同局恢复，保留调用时的版本与阈值；不重放生产，也不重算历史成果。

实现：[ExplorationStore](../../packages/runtime/src/exploration.ts)、[观察与几何](../../apps/companion/src/exploration.ts)、[探索处理器](../../packages/runtime/src/goals/explore.ts)。
