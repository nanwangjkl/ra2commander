# 自动碾压

普通攻击中的自动策略，不单独调用 Skill 或增加模型决策。执行者仅灰熊 `MTNK`、犀牛 `HTNK`、防空履带车 `HTK`；目标须符合静态可碾压规则，主动排除两类狗。配置在 [current-mod.md](../../prompts/games/current-mod.md)，未启用车型或缺失规则继续普通攻击。

只配对原命令允许的可见敌方地面步兵，并核对桥面层。多个车辆分头选择不同目标，剩余车辆继续攻击原范围内其他合法对象，不能为填满分工扩大目标类别和地域。排除狗只约束主动配对，无法改变原生碰撞。

使用公开 `ForceMove` 到目标当前格，不能用普通移动或强制对象攻击代替。目标移动后有限更新，目标失效时释放配对；新令、停车和取消优先，旧强移不得恢复。静态可碾压不保证可达或击杀，敌人消失不记为碾压击杀。

掩护继续受主体距离、行军和近身支援限制，防空合法开火优先；未交接、暂停和正在让路的成员不能被旁路接管。受阻以实际位移判断，正常绕路不因离敌距离增大而失败；有限重试后退回普通火力，回退不因下一帧或重编清零。

实现：[crushing.ts](../../packages/runtime/src/crushing.ts)、[战斗协调](../../packages/runtime/src/combat-actions.ts)、[页面桥](../../packages/game-werhd/src/bridge.js)。
