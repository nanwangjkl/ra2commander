# 基地防守

“防守基地”指攻击进入基地车或建造厂所在地图分区的敌人，没有敌人时原地待命。边界是该分区的真实多边形，不是基地周围的任意半径；成员不必先集结到基地中心。

基地收起、展开或移动跨区后追踪其真实身份和分区。基地失效时保留最后有效分区，不自动改守远处另一基地。目标类别和空地条件仍按命令保留，不转成主动全图进攻。

防守是持续任务，无敌不标为完成，范围外敌人不加入主动目标。普通攻击由游戏处理接近和开火；掩护支援与战损继续按各自约定。
