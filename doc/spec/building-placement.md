# 建筑选址

未提位置时使用普通合法选址；明确提到方位或分区时才附加约束。目标建筑的约束不传播给必要前置，也不能在失败后擅自放到其他方向、区外或旧基地。

方位按游戏画面中的八方向解释，不能把原生坐标 y 当作画面上下。指定分区使用真实多边形及孔洞；锚点与逐座方向保持绑定。普通合法性仍由引擎确认，提交成功后观察实际建筑与位置才能计作完成。

建筑完整占地之间至少隔一格，包含对角邻接；防御建筑之间可以紧贴，任一方为围墙时豁免间距。豁免仍须满足引擎合法性，不能覆盖建筑或保护中的生产集结点。防御属性按本局规则判断，不靠名字猜测。

就绪建筑由宿主持续尝试放置。暂无合法落点时保留项目、额度和方位要求，其他目标继续；不重造、不把 `place` 回执当成完成。实际出现但位置不符合时如实反馈部分结果。
