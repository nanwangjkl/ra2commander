# 生产集结与出口交接

新造坦克和步兵抵达出生时的有效集结点、脱离建筑出口并完成停车交接后，才开放编队与后续动作。矿车保留原生采矿；机场不套用地面集结，船厂不自动套用车辆出口疏通。

## 选点与到达

每次入队前复查集结点，而非只在启动时选一次。落点须为有效开阔地，周围 3×3 排除静态树石等障碍，并避开建筑、出口和不适合的地形。静态障碍不考虑树木被摧毁后的变化。到达容差为四格，但仍必须脱离建筑占地和出口，不能因出生在附近就算完成。

有效集结点与待交接产物一同保存。建筑选址保护活动集结点；需要换点时，先确认受影响的未就绪产物已收到新移动请求，再允许占用。已就绪成员不召回，后造同型单位不能冒充旧目标产物。

## 堵门与恢复

车辆长时间停在工厂中央时，结合真实位置和生产记录识别堵门，有限尝试让路或换点。不能向未交接产物下普通停车、攻击或部署，破坏其原生出厂过程；让路结束交回原协调器，不重放过期命令。

移动提交不等于抵达，失败或空回执不能记为已交接。有限恢复耗尽时报告受阻并保留产物，不用重新生产掩盖堵门。同局恢复保留集结点、成员身份和实际交接；新规则不重置产量。
