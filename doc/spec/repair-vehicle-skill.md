# 维修车 Skill

定义：[skills/repair-vehicle/SKILL.md](../../skills/repair-vehicle/SKILL.md)。

“造维修车／造修理车”按成品数量新造 IFV 和工程师，组装后持续维修；已有组件模式不补生产，自动模式只补缺项。不指定队伍时建专用维修队，指定队伍则使用该队控制对象，其他队任务继续。

组件完成原生集结与停车交接后配对，观察到工程师真正进入 IFV 才认定组装。载有其他兵种的 IFV 不算维修车，也不擅自卸载。首辆就绪即可工作，不等待整批到齐。

按全体己方坦克的实际血量识别伤员，指定目标或被支援队时缩小范围。多车优先分别修理不同伤员，保留有效分工，没有其他伤员时可协修；新伤员出现再分开。只指挥维修成员，不把受损坦克强行拉来。使用工程师 IFV 的普通攻击实现维修，不是建筑扳手或强制攻击，也不设置射程拒绝。

无伤员持续待命，指定跟随队时靠近其主体，不能标成整项完成。临时拒绝或个别受阻不阻塞其他车辆；目标修满或失效后释放分工。组件损失不补造，固定准备结束后没有可工作成员才如实结束。

配对、载员身份、分工和成功动作同局恢复；新令与取消停止旧流程后续步骤，不重播生产，暂停不累计停滞。参数与来源模式查 Skill；实现：[planRepairs](../../packages/runtime/src/repair.ts)、[能力绑定](../../apps/companion/src/capabilities/repair-vehicle.ts)。
