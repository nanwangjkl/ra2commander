# 运行状态与调试边界

操作命令集中在 [AGENTS.md](../../AGENTS.md)，完整终端语法由 `help` 输出，解析实现为 [commands.ts](../../apps/companion/src/commands.ts)。本页只保留状态与恢复约定，专题行为从[文档入口](../README.md)查阅。

## 执行状态

命令卡片汇总真实目标：全部完成才完成，仍有目标运行就显示执行中；待编译、等待前序、等待交接、待命和真正错误分别呈现。普通脚本合并属于等待，不记为错误。脚本版本表示某控制对象的代码替换，不等于命令序号；本机目标增改不增加代码版本。

调用游戏 API 不等于产出、抵达或击杀。普通改令准备失败保留旧生效任务，新要求显示待生效或失败；停止、暂停和取消直接处理。目标终态冻结旧事实，不能干扰后来生产或恢复旧行动。对局公开终态先结束调度，不以单位暂时消失做战损结算。

## 检查点与故障

`.runtime/state.json` 是 v4 检查点，兼容 v3；旧 v1/v2 不自动合并，首次格式升级保留备份。恢复须当前公开快照证明同局，保留目标身份、产物、归属、交接、Skill 与阶段事实；不确定提交继续待确认，不自动重放。无执行方式标记的旧目标继续脚本，回退只交接同一目标，不重建进度。

`.runtime/battles/` 是复盘档案，卡片可从同局归档恢复，读取它不恢复任务。未找到可恢复目标的中断命令只显示已中断，不重新解释执行；新对局不能吸收旧卡片或动作。

脚本故障与固定目标故障分别处理，见[有限修复](../spec/automatic-recovery.md)。生产未决结果不能靠重启、重编或重置账本解决；人工确认后才使用 `goal resolve` 修正发送状态。

## 开发调试

终端与本机 TCP 命令集相同，可在模型生成期间接收控制命令。`cap` 调用和自然语言共用基础能力；底层直接移动、攻击仅供调试，操作受运行任务控制的成员前先停止相关控制对象。

`task` 的显式地域、战损回撤条件及队列暂停参数是调试契约，不代表已有任意自然语言条件解析。队列编号与参数以 `help` 和能力定义为准；不能绕过玩家目标擅自暂停其他生产。

六句实机场景使用 [voice-six-commands.json](../../tests/scenarios/voice-six-commands.json)，会调用云模型并实际下令，须用户明确要求、新冰天雪地对局只有基地车；同局续测使用 `--resume`。它不属于离线测试，不采集画面或生成报告。
