# 游戏公开 API 接入边界

固定参考为 [ra2web](https://github.com/ra2web/ra2web.github.io) 提交 `7f6858ac8c1d1b7e6c9c5d84dcc1e9af1df3a06c`。接口原文见[类型声明](https://github.com/ra2web/ra2web.github.io/blob/7f6858ac8c1d1b7e6c9c5d84dcc1e9af1df3a06c/werhd-player-api.d.ts)和[玩家 API 文档](https://github.com/ra2web/ra2web.github.io/blob/7f6858ac8c1d1b7e6c9c5d84dcc1e9af1df3a06c/docs/player-console-api.md)。本页保留接入限制，完整字段与方法不再复制一份。

`window.werhd` 只存在于对局页面，没有 Node 控制 SDK。固定页面桥只访问公开 API，不调用游戏内部类。离局后引用失效，接口没有稳定对局 ID，本机维护会话代次与快照身份。

`onTick` 只有一个回调槽，超时或抛错可被游戏停用。回调必须短小，不能执行模型请求、生成脚本或原生识别；运行时在外部读取快照并提交动作。

| 接口缺口 | 实现必须承担的限制 |
| --- | --- |
| 没有完整当前订单、攻击目标或可靠命中事件 | 只追踪自身确认发令和公开血量/弹药等事实，不宣称精确击杀归因 |
| 没有路径或可达性查询 | 有效地图格、已揭开、可通行分别判断，移动回执不证明能到达 |
| 没有全规则枚举 | 目录发现名称，本局 `rules()` 和当前可造清单确认实际条件 |
| 没有统一完成回执 | 提交与效果分离；车辆/步兵队列观察可能不完整，实际产物身份仍须跟踪 |
| 没有编号编队管理 | 项目维护唯一归属与停车交接 |
| 没有禁止追击开关 | 普通攻击交给引擎，明确守区及掩护以观察和有限纠偏约束 |
| 没有地图名称或文件哈希 | 当前单图配置自动绑定冰天雪地，不按 200×200 尺寸猜图 |

可见单位不等于屏幕内单位，已揭开不等于当前视野。相同地图名不保证几何一致，静态地图不能推断隐藏敌情。画面方向与原生坐标轴不同，分区须按具体文件校准。

生产资金由引擎逐队列扣款，类别暂停没有单项无损插队能力；来源不明的暂停不能认领。放置可能被引擎静默拒绝，必须观察真实建筑，不能只看 `canPlace` 或订单回执。

维修车用工程师 IFV 的普通攻击，建筑维修用原生扳手，车辆停靠维修厂又是不同动作，不能混用。常规攻击不加射程门禁，掩护支援才使用当前武器与最终射程复查，见 [ADR 008](../decisions/008-command-actions-and-engine-attack.md)。

桥实现：[bridge.js](../../packages/game-werhd/src/bridge.js)、[page-bridge.ts](../../packages/game-werhd/src/page-bridge.ts)。升级上游需重核接口与固定清单；早期性能和接入实验在 Git 历史中，不作为当前延迟承诺。
